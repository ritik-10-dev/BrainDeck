# AI Study Hub
10 AI tools in one website (HTML/CSS/JS). Works in **Demo Mode** without a key; add a Gemini/OpenAI/Claude key in ⚙ Settings for live AI.
## Deploy on GitHub Pages
1. Create a new public repo, upload `index.html`, `css/`, `js/`, `README.md`.
2. Repo → Settings → Pages → Source: *Deploy from a branch* → `main` / root → Save.
3. Your live link: `https://<username>.github.io/<repo>/`
## Google Sheets (Task 5)
Paste the Apps Script from the Sheets tab, deploy as Web App (Anyone), paste URL in ⚙ Settings.
